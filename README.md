# DeepSeek Harness plugins

Plugins for the [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) web interface. Each plugin lives in its own repository.

| Plugin | Description | Repository |
| --- | --- | --- |
| Everforest | Six complete Everforest palettes (hard / medium / soft × dark / light) for the whole interface, with a depth picker in Settings → General | [dsh-theme-everforest](https://github.com/Frost-rA9/dsh-theme-everforest) |
